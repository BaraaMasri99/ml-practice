
## Pandas

Learning pandas through [Kaggle's Pandas micro-course](https://www.kaggle.com/learn/pandas) — free, hands-on, with graded exercises after every concept.

Course lessons: Creating, Reading and Writing → Indexing, Selecting & Assigning → Summary Functions and Maps → Grouping and Sorting → Data Types and Missing Values → Renaming and Combining.

Once finished: a full mini-analysis on a real Kaggle dataset (e.g. Titanic or housing prices), end to end, to make it stick.

- `01_series_basics.py` — Creating a Series, custom index labels, mean/max/min
- `02_dataframes.py` — Building a DataFrame, adding columns, sorting
- `03_data_exploration.py` — head(), info(), describe(), shape
- `04_missing_data.py` — Detecting, dropping, and imputing missing values
- `05_reading_files.py` — Reading CSV, Excel, SQL, JSON
- `06_groupby.py` — Grouping, sorting, and aggregating data
